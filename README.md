# panels-SolarSport
SolarSports App de seguimiento de terrazas solares instaladas en locaciones deportivas.
Aplicación de Gestión de Terrazas Solares SolarSport
Descripción
Esta aplicación permite a los usuarios registrar terrazas solares en instalaciones deportivas para realizar un seguimiento de la producción y eficiencia energética. Además, proporciona la capacidad de visualizar el consumo energético de cada instalación y recibir recomendaciones para mejorar la eficiencia energética. La aplicación incluye varias vistas clave para una experiencia completa de monitoreo y gestión.

Vistas de la Aplicación:
1. Pantalla de Inicio
   Descripción: Muestra la pantalla de inicio al abrir la aplicación desde el dispositivo móvil.
   Funcionalidad:
   Ofrece opciones para Iniciar Sesión o Crear Cuenta.
2. Pantalla de Login
   Descripción: Permite a los usuarios iniciar sesión en la aplicación utilizando sus credenciales.
   Funcionalidad:
   Permite ingresar correo electrónico y contraseña.
   Ofrece opciones para crear una nueva cuenta o recuperar la contraseña en caso de olvido.
3. Pantalla de Registro
   Descripción: Permite a los nuevos usuarios registrarse en la aplicación.
   Funcionalidad:
   Solicita los siguientes datos para el registro:
   Nombre
   Apellido
   Correo electrónico
4. Teléfono
   Contraseña
   Confirmación de contraseña
   Aceptación de términos y condiciones
   Incluye un botón para completar el registro.
4. Pantalla Principal
   Descripción: Vista principal desde la que el usuario puede acceder a otras secciones.
   Funcionalidad:
   Accede a las secciones de Estadísticas, Categorías y Consejos.
   Ofrece la opción de cerrar sesión, con confirmación requerida.
5. Pantalla de Estadísticas
   Descripción: Muestra indicadores de producción y consumo de energía de la terraza solar.
   Funcionalidad:
   Presenta un informe con gráficos y métricas sobre el comportamiento de la terraza solar.
6. Pantalla de Categorías
   Descripción: Muestra información sobre las instalaciones deportivas con terrazas solares.
   Funcionalidad:
   Permite ver fotografías de la instalación, tipo de instalación y número de paneles.
   Ofrece la posibilidad de desplazarse entre diferentes instalaciones o volver a la vista principal.
7. Pantalla de Consejos
   Descripción: Proporciona recomendaciones para el ahorro de energía y mantenimiento de las terrazas solares.
   Funcionalidad:
   Incluye un enlace a una vista con información y recomendaciones.
   Permite volver a la página de inicio si se desea.
   Funcionalidades Clave
   Registro y Login: Gestión de usuarios con opciones de registro, inicio de sesión y recuperación de contraseña.
   Visualización de Datos: Presentación de estadísticas gráficas y detalladas sobre la producción y consumo energético.
   Categorías e Instalaciones: Información sobre las instalaciones deportivas y las terrazas solares.
   Recomendaciones: Consejos prácticos para mejorar la eficiencia energética y el mantenimiento.
